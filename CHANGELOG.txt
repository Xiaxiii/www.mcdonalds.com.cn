- 连接 → 副 API：上面「内部 AI 分流」两张功能卡（推荐缝合位置、回复语义审查），卡头有测速，下面整行是模型框：绿点是用渠道，空心点是跟随主 API（直接写出主 API 的模型），橙点是选过的渠道已失效。点模型框弹出与框等宽的下拉，首项跟随主 API，多于 5 项时有搜索，底部「＋ 添加渠道」，加完直接用在这项功能上。功能卡上没有编辑按钮。
- 副 API 渠道：每个渠道一张卡，第二行写模型和来源，测速通过后行首写「可用 · 0.4s」，失败原因另起一行。右边测速和指派胶囊（选用 / 缝合在用 / 审查在用 / 2 项在用），点胶囊直接指派或改回跟随主 API，上面的功能卡跟着变。功能卡和渠道卡测同一个目标时，两处的闪电一起转、结果一起出。
- 副 API 渠道：同一个主 API 站点来的渠道有两个以上时合成一张卡，写「含 某模型、某模型」，组里有在用的就在「N 个 ▸」左边写出来；展开后子行去掉站点名前缀，底部一行「添加「站点名」的其他模型…」。渠道标题右边加 ⋯ →「排序与删除」，可拖动排序（同源组整组移动）、删除；渠道的顺序也是下拉里的顺序。

- 全站：分段选项选中时底下的白块滑过去；连接、预设、检查、更多的页签下面一条墨线滑到选中的页签，点页签换页时内容轻浮入场。贴着按钮弹出的菜单关闭时淡出。说明（ⓘ）展开收起有过渡。按下按钮统一缩到 96%。系统开了「减弱动态效果」时这些动效都不播。

1.8.0
数据安全
- 保存前先核对酒馆里的预设有没有被别处改过（酒馆、百宝箱、其他设备）。改过就暂停自动保存，由你选择：下载两个版本、放弃自己的修改，或覆盖。
- 页面重载后发现未保存的草稿：服务器上的预设没变过才自动接着保存；变过就先问你，不再直接覆盖。
- 自动备份失败时不再照常写入，会让你选择：下载修改前的版本后保存、不备份直接保存，或暂不保存。
- 归档：上传后读回来逐字核对，核对不上或读不到都不删原预设。归档文件名带上预设名。
- 添加站点、获取模型列表时不再换掉酒馆正在用的密钥；密钥保存失败会提示，不再显示成功。取消添加时，刚存进密钥库的密钥一并删掉。
- 删除预设时提示它正被哪些方案、连接配置使用。
- 世界书「内容完全相同」改为比较条目的全部设置（启用、概率、位置、深度等）。
- 删除世界书时，读取失败、没有备份下来的那本不再删除。
- 扩展数据：任何一个文件没读到都算「没查完」；去掉「一键清理」，改为「勾选疑似残留」，逐项确认后再删。
- 缝进世界书前先备份整本世界书；缝完可在底栏撤销刚缝进去的条目。
- 套用方案前，先保存这个预设上没存完的修改，不再直接丢掉。
